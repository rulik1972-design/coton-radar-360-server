# COTON RADAR NETWORK 10 — інструкція українською

## Що отримуєш
- Один сервер Render із 10 окремими комплексами `RADAR-01` ... `RADAR-10`.
- Один диспетчерський екран на ноутбуці: 10 радарів одночасно, окремі стани ONLINE/OFFLINE/ALARM, перегляд кожного на весь екран.
- **Локальна демонстрація без SIM800L** кнопкою «Увімкнути ДЕМО». Демо не записує фальшиві дані на сервер.
- Arduino-прошивка для **кожного** ESP32-P4 + три RD-03D + SIM800L; прошити 10 плат, змінюючи лише `RADAR_ID` та персональний `DEVICE_KEY`.
- `heading_deg` — необов’язкове поле для майбутнього компаса; поки компаса немає, сервер використовує 0°, а на панелі показує «немає компаса».

## ОНОВЛЕННЯ НАЯВНОГО Render-сервера
1. У GitHub відкрий існуючий репозиторій `coton-radar-360-server`.
2. Замінити файл `app.py`, `templates/index.html`, `static/app.js`, `static/style.css` файлами з папки `server` цього архіву. `requirements.txt`, `render.yaml` залишити наявні або замінити вкладеними.
3. У Github натиснути `Commit changes` після завантаження, Render автоматично почне новий deploy (за ввімкненого Auto Deploy).
4. На Render залишити поточні `VIEW_USER`, `VIEW_PASSWORD`, `DEVICE_KEY`; вони потрібні для авторизації. `DEVICE_KEY` продовжить працювати для старого однорадарного відправника `RADAR-01`.
5. Відкрий `https://coton-radar-360-server.onrender.com/` та ввійди звичайним логіном і паролем. Натисни «Увімкнути ДЕМО». Десять радарів — на одній сторінці; клік по одному відкриває великий радар.

## ДЕСЯТЬ СПРАВЖНІХ КОМПЛЕКСІВ — КЛЮЧІ
Щоб підключити окремо всі 10 пристроїв, на Render → Service → Environment створи **одну** змінну `RADAR_KEYS` з JSON-об'єктом:

```json
{"RADAR-01":"UNIQUE_SECRET_01_CHANGE_ME_123456789","RADAR-02":"UNIQUE_SECRET_02_CHANGE_ME_123456789","RADAR-03":"UNIQUE_SECRET_03_CHANGE_ME_123456789","RADAR-04":"UNIQUE_SECRET_04_CHANGE_ME_123456789","RADAR-05":"UNIQUE_SECRET_05_CHANGE_ME_123456789","RADAR-06":"UNIQUE_SECRET_06_CHANGE_ME_123456789","RADAR-07":"UNIQUE_SECRET_07_CHANGE_ME_123456789","RADAR-08":"UNIQUE_SECRET_08_CHANGE_ME_123456789","RADAR-09":"UNIQUE_SECRET_09_CHANGE_ME_123456789","RADAR-10":"UNIQUE_SECRET_10_CHANGE_ME_123456789"}
```

**Це тільки зразок, не використовуй ці значення як реальні ключі!** Згенеруй 10 різних випадкових секретів (не менше 16 символів кожен), збережи їх приватно, внеси в Render і в `secrets.h` відповідних 10 комплексів. Не додавай свої ключі в публічний GitHub. `VIEW_PASSWORD` та ключі на скриншотах закривай.

## Передача даних
`POST /api/ingest`, Content-Type `application/json`, `X-Device-Key: <key>`.
Тіло — наприклад:

```json
{"device_id":"RADAR-03","sequence":42,"sensors":[true,true,true],"targets":[{"sector":2,"x_mm":1200,"y_mm":3500,"speed_cm_s":-35}],"heading_deg":30}
```

Кожна станція надсилає тільки власні координати. Стани інших не перезаписуються. Після 7 секунд без коректного пакета відповідний радар стане OFFLINE.

## Прошивка ESP32-P4
В папці `firmware/COTON_RADAR360_P4_SIM800L_NETWORK10` є `.ino`, `radar_types.h`, `secrets.h`. Для RADAR-01 встанови `#define RADAR_ID "RADAR-01"` та його секретний ключ. Для RADAR-02 — інший ID і ключ, так само до RADAR-10. Поки SIM800L фізично відсутній, `ENABLE_GSM_MODEM 0` — три RD-03D читаються локально, але на Render нічого не надсилається. Зміни його на 1 лише після реального підключення SIM800L.

### Обмеження
- SIM800L використовує GPRS/2G; сумісність його HTTPS/TLS із Render **не підтверджена**. Не передавай DEVICE_KEY незашифрованим HTTP. Навіть якщо скетч збирається, це не гарантує успішного передавання даних із SIM800L до Render.
- Безкоштовний Render засинає / перезапускається. Оперативна пам'ять сервера не є постійним сховищем. Непридатно як єдина критично важлива охоронна система.
- Компас фізично не підключений: heading_deg — підготовлений для майбутнього обладнання, **не виміряний курс**. Для точного курсу потрібні калібрування та врахування магнітного схилення.
- Поточна Arduino-розпіновка базується на попередній успішній перевірці трьох RD-03D на твоїй платі. Живлення SIM800L потребує окремого стабілізатора, а логічні рівні UART — перевірки.
