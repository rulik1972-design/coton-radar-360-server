# COTON RADAR 360 — сервер для Render Free

Це тестовий сервер для **ESP32-P4 + 3 × RD-03D + SIM800L (GPRS)**. Телефон показує радар 360°, оновлення та тривогу при наявності будь-якої актуальної цілі. Деморежим **тільки в браузері**; справжні дані він не підміняє.

## Розгортання

1. Створіть репозиторій GitHub (краще приватний) і завантажте в його корінь файли **з папки** `coton_render_server` (app.py, requirements.txt, render.yaml, templates/, static/ тощо).
2. На [dashboard.render.com](https://dashboard.render.com) виберіть **New → Web Service**, підключіть репозиторій. Runtime: Python, план: **Free**. Build: `pip install -r requirements.txt`; Start: `gunicorn --workers 1 --threads 4 --bind 0.0.0.0:$PORT app:app`.
3. У **Environment** встановіть `DEVICE_KEY` (довгий випадковий секрет для радара), `VIEW_USER` (наприклад, `radar`) і `VIEW_PASSWORD` (інший сильний пароль для браузера). **Секрети не додавати у файли GitHub.**
4. Після деплою Render дасть адресу `https://ВАША-НАЗВА.onrender.com`. Відкрийте в браузері й увійдіть з `VIEW_USER` та `VIEW_PASSWORD`. Натисніть кнопку **Увімкнути демонстрацію**.

## Тест POST

Приклад (Windows PowerShell, замініть URL та ключ):

```powershell
$headers = @{"X-Device-Key"="ВАШ_СЕКРЕТ"}
$body = Get-Content -Raw .\example_packet.json
Invoke-RestMethod -Uri 'https://ВАША-НАЗВА.onrender.com/api/ingest' -Method Post -Headers $headers -ContentType 'application/json' -Body $body
```

Після запиту відкрийте сайт радара: дані будуть активні 7 секунд. У JSON `sensors` — три булеві значення; `targets` — до 9 цілей у локальних координатах секторів 1–3; поля `x_mm`, `y_mm`, `speed_cm_s`.

Сервер повертає `alarm=true` лише якщо є хоча б одна актуальна ціль, і `OFFLINE` через 7 секунд без нових пакетів. Дані зберігаються лише в оперативній пам'яті й губляться при перезапуску, що нормально для тесту.

## Критична примітка щодо SIM800L

SIM800L — 2G/GPRS-модем. **Цей сервер очікує HTTPS із секретом у заголовку.** Робота HTTPS/TLS конкретної версії прошивки SIM800L із сучасним Render TLS не гарантована. Не надсилайте `DEVICE_KEY` відкритим HTTP! Спочатку перевірте, чи ваш модем підтримує узгодження TLS із Render; якщо ні, потрібен перевірений захищений транспорт/шлюз або сучасний LTE-модем. Прошивка ESP32-P4 під SIM800L сюди поки не входить.

## Обмеження Render Free

Без активних запитів приблизно 15 хвилин вебсервіс засинає; наступний запуск займає приблизно хвилину. 750 безкоштовних годин на робочий простір за календарний місяць; сервіс може перезапускатись. Цей варіант **не призначений для критично важливого або безперервного сповіщення**.
